Mickey's Clock
Clock built with Pygame. Mickey's right hand = minutes, left hand = seconds. Time is taken from the system clock (minutes and seconds only).
Run
pip install pygame
python main.py
Press Esc or close the window to quit.
Files
main.py - window and main loop
clock.py - MickeyClock class (time, angles, rotation, drawing)
images/mickey_hand.png - hand image (must point UP, wrist at bottom center)
